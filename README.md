## Learning Path

A practical progression for this collection is:

1. Start with **WPScan Deep Recon** to introduce web reconnaissance.
2. Continue with **Beelzebub User Enum** and **Beelzebub Directory Hunt** for enumeration concepts.
3. Study **Hash Headers Hunt** and **Header Shadow Hunt** for HTTP header-based clues.
4. Use **DevTools Sleuth** to practice browser-side investigation.
5. Move to **Hidden Pages Unmasked**, **Uploads Hints Hidden Paths**, and **Dir Search Secrets** for web content discovery.
6. Finish with **Traffic Sniffers** and **Post Packet Secrets** for traffic and packet-oriented investigation.

## How to Use the Labs

1. Open a lab using the direct links above.
2. Read the lab instructions and scope carefully.
3. Perform the exercises only in the environment authorized by the lab provider.
4. Record useful observations, commands, discovered paths, and investigation steps.
5. Focus on understanding why each discovery method works rather than simply completing the challenge.
6. Document lessons learned for future CTF and defensive security work.
